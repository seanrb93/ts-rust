Pumpkin Jack: a character made from nothing (a scarecrow with a pumpkin head), as an example of a new character.
examples/pumpkin_mod_src/make-pumpkin.py draws the figure as solid pieces, each in an object named for the bone that moves it (bone8 and so on, see tools/obchar.py); tools/obchar.py turned the figure into this mod.
Copy this folder into mods/ (a build with extended-tables).
