BlueRobot as a bot (the game never lets him be chosen as a player: he has no front end model, and a playable BlueRobot broke every texture of the front end, so `chrPlayable` says no for him in the extensions build).  The patches make him available in the bot sets.  Copy this folder into `mods/` next to `ts-rust.exe`; on the bot sets page the last place of the character list is BlueRobot (the select page skips him).  Needs the build with the extensions feature (`python tools/build-game.py`).
