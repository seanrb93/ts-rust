Smooth Weapons: the guns with more polygons, added only where they are curved: barrels, drums, grips and the rims of tubes go round, and flat sides and sharp corners stay as they are.
Run `python tools/make-smooth-weapons.py <game>/PAK/OB.PAK <game>/mods` to make the mod (about 8 MB: it holds the game's own models, so they are not kept in the repository).
With First Person Hands on, the guns in your own hands are that mod's (its models have the arms on them), so only the guns seen in the third person are smooth.  Making that mod from these guns (HANDS_BASE=<this mod's folder> for make-hands.py) is not usable as it is: it came to 3.4 GB, and a pack over 2 GB hangs the game, whose offsets in a pack are signed.  Finer curves (a smaller TOLERANCE in the script) run out of the game's memory in a match, so check a real match after changing it.
Switch it on or off from the Mods page (or enabled = true) and start the game again.
